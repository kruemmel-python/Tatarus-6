C ABI

include/tatarus/c_api.h stellt Handles für Mind und Organismus bereit. Die ABI deckt Erzeugen/Zerstören, Beobachten, Explorer/Identity, Telemetrie, Action-Lifecycle, Snapshot, Organismus-Interventionen, Spatial/Live/Physiology/Throughput-JSON, Environment Map, IMAGINATIO-Lernen/Recall/Kategorie/Szene/Render und Cortex-Konfiguration/Ziele/Working-Memory/Kommandos ab.

Fehlerbehandlung

Die C ABI liefert Statuswerte und stellt den letzten Fehler über tatarus_last_error() bereit. Buffer-basierte JSON-Funktionen unterstützen zunächst eine Größenabfrage und anschließend die Ausgabe in einen vom Host bereitgestellten Puffer.

Vertragsregel

Hostprogramme sollen keine internen Datenstrukturen rekonstruieren. Öffentliche Header und C-ABI sind die stabile Integrationsgrenze; Zustandsdetails werden über Telemetrie und JSON-Sichten gelesen.

Build-Qualitätsgate

Compilerwarnungen sind Buildfehler. Die CMake-Konfiguration erzwingt diese Regel global; die Kern-Targets aktivieren zusätzlich strenge Warnstufen für MSVC beziehungsweise GCC/Clang.

Kausale Prüfungen

Die Testbasis umfasst unter anderem Blutverlust → Blutvolumen/MAP/Sympathikus/Renin, Hypoxie → PaO₂/Chemorezeptor/Atemantwort, Hyperkapnie → PaCO₂/pH/Ventilation, renale Hypoperfusion → GFR/Macula-densa/Renin und mechanische Last → O₂-Bedarf/Ventilation/Herzlast. Weitere Tests prüfen Marsatmosphäre, Körperversorgung des Nervensystems und Bilanzierung.

Snapshot-Prüfungen

Tests prüfen deterministische Fortsetzung nach Restore. IMAGINATIO prüft Farblernen, Self-Motor-Gedächtnis, Kategorie- und Szenenzustände sowie hochauflösendes Zielraum-Rendering. Cortex-Tests prüfen Zustandsneutralität des Sandboxes, Safety-Vertrag und Record/Replay.

Interpretationsgrenze

Ein bestandener Test beweist die implementierte Invariante, nicht biologische Vollständigkeit. Dokumentation und Tests unterscheiden deshalb zwischen „im Code kausal gekoppelt“ und „biologisch/medizinisch vollständig validiert“.

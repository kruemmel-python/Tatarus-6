TATARUS – System-Wiki

Das Wiki beschreibt ausschließlich den veröffentlichten TATARUS-Projektstand: einen gekoppelten synthetischen Organismus mit Nervensystem, Körperphysiologie, Sinnesorganen, Gedächtnis, IMAGINATIO, Kartografie und optionalem Hybrid Cortex.

Dokumentationsprinzip: Keine Entwicklungschronik. Jede Seite beschreibt, was der aktuelle Code tut und wo die Systemgrenzen liegen.
